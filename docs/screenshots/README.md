1200×777) are **2.2-era live evidence** captured on 2026-11-15. They are kept
because they show the panel layout and the long-message/audit states, not because
they represent 2.4.

- times use `HH:mm` with sticky day separators;
- the target menu is viewport-anchored;
- pause, relay, settings and the language switch are new.

Do not quote these images as a 2.4 acceptance record. The 2.4 matrix and the
evidence-file helper are in [UI-ACCEPTANCE.md](../UI-ACCEPTANCE.md).
