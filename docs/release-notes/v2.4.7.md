## Group-Chat 2.4.7

Release artifacts and checksum.

- The tag-driven release workflow now runs `npm pack`, writes `SHA256SUMS`, and
  attaches both the tarball and the checksum file to this GitHub Release.
- Verify a download with `shasum -a 256 -c SHA256SUMS` after placing both files
  in one directory.

This release contains everything from 2.4.0–2.4.6: reply owner for wide sends,
relay references, in-panel digest, optimistic send, credential scanning,
broadcast preview, pause/emergency stop, circuit breaker, retention/redaction,
bilingual panel, adapter/MCP boundary, and the release automation itself.
