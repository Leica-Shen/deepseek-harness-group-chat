## Group-Chat 2.4.5

Release automation and the last integration polish on the 2.4 line.

### What this release contains

The full 2026-11-17 review implementation (2.4.0) plus the patches:

- **2.4.1** — relay replies are charged; malformed relay rows no longer make the
  store read-only; mailbox hosts do not gate membership on inbox existence;
  read-only stores skip maintenance writes; ambiguous group names show candidates.
- **2.4.2** — credential scanning covers audited notes and `refs`; authorization
  payloads are rejected for every relay intent, not only `confirm`.
- **2.4.3** — optimistic send: the local row appears before the delivery
  round-trip and the composer stays usable.
- **2.4.4** — relay `refs`; deterministic in-panel digest; sidebar stops polling
  after two empty snapshots; GET shrinks the per-room window when the body would
  exceed 1.2 MB.
- **2.4.5** — this Release is created by the repository's own Actions workflow
  (`GITHUB_TOKEN`), so it no longer depends on a local `gh`/token.

### Feature summary

- Existing DSH sessions join a room; `@alias` / `#role` / `*`; the human is an
  in-room principal.
- Audited notes/decisions, bounded subagent delegation, one-to-one relay with
  five hard-coded red lines.
- Credential scan and taint labels; broadcast preview; pause/emergency stop and
  a broadcast circuit breaker; per-group sensitivity; retention/redaction;
  redacted export.
- Three-state language switch; stable `roleId` routing; messages-first layout;
  avatars, day separators, search, mute/hide/mark-all-read.
- Adapter contract + mailbox adapter + MCP server; compatibility matrix.
