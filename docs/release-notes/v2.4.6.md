## Group-Chat 2.4.6

A wide send now names one reply owner, so a broadcast no longer invites everyone
to answer at once.

### Highlights

- **Reply owner.** For a `*`/multi-recipient send, an organizer/owner recipient
  is chosen first; otherwise the first session target. The envelope carries
  `replyOwner` plus a bilingual instruction, and the policy says other members
  stay silent unless correcting a factual error. The panel shows a
  `Reply owner @alias` chip.
- Relay references (`refs`), deterministic in-panel digest, credential scanning
  for notes/refs, optimistic send, broadcast preview, pause/emergency stop,
  circuit breaker, retention/redaction, bilingual panel and MCP/adapter boundary
  are all included from 2.4.0–2.4.5.

### Upgrade

Restart Harness once. Schema 2 migrates on load; the daily ledger resets once
when switching from UTC to local midnight. Package `@leica-shen/dsh-group-chat`;
plugin id and data directory stay `group-talk-l`.
